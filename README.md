# Staton poe trade

Staton poe trade aide à estimer les objets de Path of Exile sur Windows, y compris quand tu joues via Boosteroid.

[Télécharger la dernière version Windows 64 bits](https://github.com/OliverStaton/staton-releases/releases/latest)

## Installer Staton

Dans la publication la plus récente, télécharge le fichier `.msi` dans **Assets**. Si Staton est déjà ouvert, ferme-le, puis lance le MSI. Une fois l’installation terminée, ouvre **Staton poe trade** depuis le menu Démarrer.

## Mettre Staton à jour

À partir de la version 3.30.107, Staton vérifie au démarrage si une nouvelle version est publiée ici. Lorsque le bouton **Install now** apparaît, clique dessus et confirme. Staton télécharge et vérifie l’installateur, puis se ferme pendant la mise à jour. Ouvre de nouveau Staton une fois l’installation terminée.

Les notices de licence des composants distribués sont incluses dans l’installateur.
